# 中国矿业大学校园网助手 · macOS 菜单栏版

[GitHub 项目 / 源码](https://github.com/NightCruising666/cumt-autologin-macos) · [下载 macOS 安装包](https://github.com/NightCruising666/cumt-autologin-macos/releases)

用于南湖校区 **CUMT_Stu** / **http://10.2.5.251** 的校园网认证。
当前是可运行的本地初版：原生界面和模拟协议测试已验证，真实校园网登录、注销仍需现场测试。

## 启动与设置

打开安装包 `.dmg`，将 **校园网助手.app** 拖入“应用程序”，然后双击启动。也可以直接运行应用；无需 Python、Homebrew、终端或开发工具。

DMG 打开后显示应用 → 应用程序文件夹的箭头布局；应用复制完成后，可以推出安装磁盘。

源码项目中可双击 **启动菜单栏.command**，或打开 `build/CUMT Auto Login.app`。
首次启动会打开“详细设置”。输入账号和密码、选择运营商，然后“保存设置”或“保存并登录”。

- 密码只输入一次，默认隐藏，可勾选 **显示密码** 查看当前输入。
- 修改其他设置时，密码留空会保留已存密码；更换账号必须填写新密码。
- 密码保存到 macOS 登录钥匙串，不写进配置、命令行参数或日志。
- 账号、运营商、自动登录与检测间隔保存到本机 `menu-config.json`。

此安装包适用于 Apple Silicon Mac（M 系列芯片）和 macOS 13 或更新版本。原生认证后端已经编译进应用，只依赖 macOS 系统组件。
源码重新编译才需要 Apple Command Line Tools；已打包的应用不需要安装开发工具。
本地签名尚未经过 Apple Developer ID 公证，首次打开可能出现系统确认提示。升级时先退出旧版菜单栏助手，再打开新版。

## 菜单栏功能

点击屏幕顶部的 Wi-Fi 图标，可看到连接状态、最近结果和检查时间。

| 功能 | 行为 |
| --- | --- |
| 打开校园网登录页 | 用默认浏览器打开 `http://10.2.5.251/` |
| 立即检测连接状态 | 只检查环境和联网，不触发登录 |
| 立即登录 | 用保存的账号完成认证，即使自动登录开关关闭也可使用 |
| 立即注销 | 请求注销当前设备，同时关闭自动登录，防止马上重新认证 |
| 开机自启 | 控制登录 Mac 后是否启动菜单栏助手，不改变自动登录开关 |
| 自动登录 | 开启后，检测到校园网未联网时自动认证；关闭后仍可手动登录 |
| 详细设置 | 账号、密码显隐、运营商、检测间隔与两个开关 |
| 查看日志 | 打开本机配置和日志文件夹 |
| 退出校园网助手 | 退出后停止检测；开机自启选项保持原设置 |

默认每 60 秒检查，可选 30 秒、60 秒、2 分钟或 5 分钟；唤醒后也会检查。
睡眠时不运行，后台请求不会阻塞窗口或菜单。登录失败后暂停 5 分钟，账号密码错误或设备数超限时暂停 15 分钟；手动登录可跳过等待。

状态含义：

- **已联网**：环境符合校园网条件，外网检测通过。
- **未认证 / 未联网**：校园 Wi-Fi 环境符合条件，但外网检测未通过；不单凭这一点断定密码错误。
- **未连接校园网**：当前网络不符合校园网条件。
- **路由被代理接管**：校园网地址的路由经过虚拟网卡，需要检查 TUN/VPN。
- **检测失败 / 状态待确认**：请求或门户识别未完成，不能据此确认真实认证状态。

## 开机自启与安装

打开“开机自启”开关后，会复制应用到：

```text
~/Applications/CUMT Auto Login.app
```

并写入：

```text
~/Library/LaunchAgents/local.cumt.autologin.menu.startup.plist
```

设置针对下一次登录 Mac 生效；当前已运行的助手继续工作。关闭开机自启不会退出当前应用，也不会关闭自动登录。
应用更新后，重新打开项目中的新版应用并开启开机自启，会更新固定目录的应用副本。
先前脚本版的后台任务若存在，会在启用新版开机自启时停用，避免并行认证。

## 卸载与残留

直接把 App 拖入废纸篓，只移走该应用副本，不会清理已保存的配置、日志、钥匙串密码或自启副本。推荐在 0.3.1 或更新版菜单栏中选择 **清理数据并卸载…**，阅读清理范围后确认。

卸载会停止自动登录，移除本工具的两个自启任务文件、已保存的所有校园网账号密码、`~/Library/Application Support/CUMT-AutoLogin` 中本工具的配置与日志，以及以 `local.cumt.autologin.menu` 命名的缓存、偏好和窗口状态。应用程序文件夹中的本工具副本会移入废纸篓，按 bundle ID 核验，不处理其他软件。未知文件会保留并提示；删除失败不会显示清理成功。

开发项目源码、下载的 DMG 和 ZIP、废纸篓中的应用由你自行保留或删除。macOS 自身维护的系统日志、最近使用记录等不属于本工具的清理范围。如果已把 App 删掉，可重新打开新版 DMG 内的 App，再选择该清理入口；不用重新输入校园网密码。

## 辅助双击入口

- `1-设置账号.command`：打开详细设置。
- `2-立即测试.command`：立即登录并验证联网。
- `3-安装自动登录.command`：开启开机自启。
- `4-查看状态.command`：立即检查状态。
- `5-停用开机自启.command`：关闭开机自启；当前应用仍然运行。
- `6-彻底卸载.command`：打开与菜单栏相同的清理卸载入口，执行前显示确认。

日常操作优先使用菜单栏。旧 Python 脚本保留用于协议参考和开发测试，不是新版应用运行依赖，也不与应用账号配置混用。

## 网络与凭据处理

能读取 SSID 时，要求是 CUMT_Stu。系统隐藏 SSID 时，结合 Wi-Fi 路由、校园网 IPv4 与门户终端地址和 Dr.COM/eportal 特征识别；条件不满足时不提交密码。
不强制切换 Wi-Fi，建议为 CUMT_Stu 开启系统“自动加入”。不自动注销其他设备。

使用会话 Cookie 完成 HTTP 认证，登录成功以外网检查为准。认证首页只允许同一校园网地址的跳转；携带密码的请求不自动跟随跳转。
请求绕过系统 HTTP 代理；TUN/VPN 接管校园网路由时会跳过。
校园网认证沿用学校 HTTP 接口，钥匙串的本地保存不会改变学校的传输协议。

GUI 密码的钥匙串项目为 `CUMT-AutoLogin-Nanhu-Menu`；账号为你填写的学号/工号。
后台读取不弹授权窗口；若钥匙串未解锁或未授权，在界面提示处理。首次保存/手动登录时可能出现正常钥匙串授权提示。
菜单日志 `menu.log` 单文件约 512 KiB，保留一份轮转，不记录账号密码或认证请求 URL。

## 开发与验证

```bash
./build_macos.sh
./test_native.sh
python3 -m unittest discover -s tests -v
```

制作带箭头背景的 DMG（Python 仅用于构建，不是应用运行依赖）：

```bash
python3 -m venv build/dmg-tools
build/dmg-tools/bin/python -m pip install dmgbuild==1.6.7
DMGBUILD_BIN="$PWD/build/dmg-tools/bin/dmgbuild" ./package_dmg.sh
```

`packaging/` 保存安装背景生成器和 Finder 窗口布局，后续打包可直接复用。

发布 GitHub 时，在 `app-metadata.json` 的 `repository_url` 填入本项目仓库首页（`https://github.com/用户名/仓库名`），重新运行构建和打包脚本。也可以留空，构建脚本会从 Git 的 `origin` 读取 GitHub 仓库地址。配置好后，详细设置窗口底部会显示 **GitHub 项目 · 查看源码 / Star**，点击后在浏览器中打开仓库首页。未配置地址时不显示链接，不会指向上游仓库；点击不会代替用户进行 Star。

`app-metadata.json` 的 `version` 是应用版本号来源。提交源码或设置远程仓库后，需要重新构建，已生成的 App 不会自动改变链接。

源文件：

- `macos/main.swift`：AppKit 菜单栏、设置窗口、钥匙串、自动检测、自启。
- `macos/NetworkBackend.swift`：原生 HTTP/Cookie、状态检测、登录、当前设备注销与网络检查。
- `macos/Models.swift`：状态和错误模型。
- `macos/AppCleanup.swift`：限定清理路径与应用识别；临时目录卸载测试不接触真实数据。
- `macos/MakeIcon.swift`：构建时生成应用图标。
- `gui_backend.py`、`cumt_login.py`：前版的 Python 协议参考，不随独立应用运行。
- `tests/`：模拟网络和门户，不使用真实账号。
- `upstream/`、`NOTICE.md`、`LICENSE`：原始代码和 AGPL v3 来源。

用 `open 'build/CUMT Auto Login.app' --args --preview --settings` 可以预览界面；该模式不操作真实钥匙串或网络，且不安装开机自启。
实际验证需要在南湖连接 CUMT_Stu：在本机保存账号，手动登录确认成功，再测试注销、自动补登和睡眠唤醒。

独立版验证：26 项 Swift 原生联网测试和 10 项卸载测试通过，包括真实本地 HTTP Cookie 复用与跳转限制、重复清理、未知文件保留及应用身份核验；动态依赖检查确认只链接 macOS 系统框架。真实校园网认证仍待现场验证。
